Wedding Invitation Web Application

Live Demo:
https://aienmii.github.io/wedding_invit/#story

Description

A data-driven wedding invitation web application developed for a real client. The system allows guests to view event
details and confirm attendance through an interactive RSVP feature.

Tech Stack

React
TypeScript
Vite
HTML5 / CSS3

Features
Responsive
UI for mobile and desktop

Dynamic content rendering based on guest data

RSVP system with guest selection and attendance confirmation

Data persistence using structured external data source

Smooth navigation and interactive sections

Data Handling

Processed structured guest data (Excel-based dataset)

Implemented client-side parsing and mapping of guest information
Linked RSVP responses to specific guest records
